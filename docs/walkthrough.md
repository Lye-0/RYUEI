# 制作者向け攻略・進行仕様

**全解法と結末を含む。通常プレイ前には読まないこと。**

| 対象         | 写真内の操作                                                                   | 結果                                               |
| ------------ | ------------------------------------------------------------------------------ | -------------------------------------------------- |
| 受付の側板   | 三つの押さえをそれぞれ回す。順不同。板を引く                                   | 廊下の鍵                                           |
| 廊下の扉     | 鍵を選び扉へ使う。扉を開き、開口部を押して進む                                 | 展示廊下                                           |
| 四枚の写真   | 無傷→裂け目と立つ花瓶→裂け目と割れた花瓶→修理。二枚ずつ交換                    | 引き出しに暗室の鍵と電球                           |
| 保管棚       | 図の区画内の放射状の飾りを基準に左右を戻し、右上・左下・中央下の押し板を沈める | ハンドルと乾板                                     |
| 作業灯       | 電球を入れ、腕を二段下げる                                                     | 紙に残った押し跡。右の引き出しの鋏は独立して取れる |
| 壁の搬送口   | 三日月側から、下から数えて左1右4→左3右2→左4右3。各組でハンドルを回す                             | 蓋の中のレンズ                                     |
| 台紙         | 鋏を使い、上中央・中央右・左下の窓を開く                                       | 三枚のガラス                                       |
| 現像         | 乾板を入れ、黒→白→灰→水                                                        | 乾燥用の引き出しに写真                             |
| 撮影機       | レンズを入れる。台車は右、焦点は中央、レンズは高い位置                         | 下の収納にレリーズ                                 |
| 照明         | レリーズを接続。五枚の影に対し、右→右→上→左→左                                 | 小さな収納に幕のハンドル                           |
| 景色         | 写真を掛け、扉の左半分→右半分→窓の左半分→右半分                                | 小箱に裏室の乾板                                   |
| ガラス       | 三枚を置く。初期から一枚目を二回、三枚目を一回回す                             | 弧と枝の輪郭がつながる                             |
| 背景幕       | 景色とガラスを揃え、右の軸にハンドルを入れて回す                               | 幕が上がり裏室へ。図面上の答え合わせはない         |
| 裏室の送り口 | 三つの鋲側から、左3右4→左2右3→左4右1。各組でハンドルを回す                      | 印画紙                                             |
| 焼付け       | 乾板と紙を枠へ入れ、光→黒→白→水                                                | 最後の写真                                         |
| 搬出口       | 最後の写真の裏面を読む。窓が逆側なので、右→左→右→中央                          | 扉を開け、外へ進む                                 |

資料は写真内で見つける。保管棚の脇の紙、作業灯の下の台紙、壁の試し撮りや配置図などを調べる。現像処理は館内の見本をルールとし、専門知識を要求しない。

正解を知る自動操作で、初見の難易度や所要時間を評価しない。今後の初見テストでは、考えた時間と、物が見つからない・操作が分からないために止まった時間を分ける。
