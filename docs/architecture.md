# 実装構成

部屋の写真、拡大、機構の変化、当たり判定を同じ世界座標で描く。拡大専用の別写真へ切り替えない。

| ファイル                | 役割                                                           |
| ----------------------- | -------------------------------------------------------------- |
| `src/Scene.tsx`         | 一つの写真空間の描画、カメラ移動、写真内の操作と反応           |
| `src/sceneGeometry.ts`  | 部屋ごとの基準画像、対象範囲、拡大範囲、部品・収納・紙面の位置 |
| `src/SceneDocument.tsx` | 手に取った写真、記録、現物から切り出す持ち物画像               |
| `src/Photo.tsx`         | 採用画像の参照、切り出し、反転、読み込み失敗表示               |
| `src/data.ts`           | 部屋・品物・謎・手掛かりの定義                                 |
| `src/engine.ts`         | 進行、設置、開閉、取得、保存の検証                             |
| `src/App.tsx`           | 視点、持ち物、最小限のメニュー、自動保存                       |

## 写真と操作

世界座標は100×100。写真と操作領域を同じ親要素に入れ、親だけを拡大・移動する。紙面とガラスは四隅に射影し、レバーは基準写真から切り出した同じ部品を回転させる。

生成した開閉写真は、対象の部分だけを基準写真に重ねる。取得後は空の収納写真を品物の範囲に重ねるため、二つ入っていた物の片方だけも消せる。部屋へ戻っても同じレイヤーを描く。状態写真は部屋に入った時点で先読みする。

操作は写真内で完結する。写真を入れ替える、押さえを回す、腕やレバーを動かす、紙を槽に入れる、取っ手を引く。汎用的な答え合わせボタン、選択数表示、謎に直結する手掛かりボタンは置かない。正しい機構の状態に達すると、その場で反応する。任意の救済はメニュー内に置く。

## 状態

- 機構の成立、収納の開閉、品物の取得は別状態。作業灯と無関係な引き出しは、灯りを解く前から開けられる。
- 扉は解錠・開扉・移動を分離する。開いている扉に鍵を要求しない。
- 電球・レンズ・レリーズ・写真・ガラス等は設置先へ移り、持ち物からなくなる。ハンドルと鋏は、使って戻せる道具として残る。
- 保存キーは既存のものを保つ。旧版の移動済み扉、二軸だった灯り、設置後も持ち物に残っていた材料を読み替える。
- 写真を読んだ履歴自体を正解条件にしない。

## 接続

受付―展示廊下。展示廊下から修整室・暗室・撮影室。撮影室の幕の奥が裏室。暗室と撮影室の小さな受け渡し口は、人が通る通路ではない。

## 素材

`public/images/rooms/<部屋>/views` に全景、`states` に同じ視点の状態写真、`clues` に資料、`mechanisms/fragments` に交換する写真、`ending` に結末を置く。採用画像だけを配信する。`src/assets.json` と `docs/assets/manifest.json` の容量・寸法・SHA-256を監査する。

変更時は全体→拡大→途中→開閉→取得後の写真を対で比較する。入力テストの成功だけで視覚的な一致を確認したことにしない。画面幅を変えて、対象物そのものを触れるか、隣の物が反応しないかも確認する。

静的アプリでバックエンドは不要。フォントはローカルの明朝体を使い、外部フォント配信に依存しない。公開・デプロイは行っていない。


## 難易度を保つ修正方針

ユーザー指定（2026-09-19）: 見た目・当たり判定・操作の反応を修正するときも、謎を簡単にしない。押した物が沈む、取り付けた物が残る、といった操作後の反応は明瞭にする。一方、通常の手掛かりに指のジェスチャー、答えの位置への矢印、操作手順の直説を足して推理を代行しない。対応関係、向き、順序、意味をプレイヤー自身が読み解く余地を維持する。任意に開く段階式ヒントと通常の観察文を区別し、観察文が答えを先回りしていないか画像と一緒に点検する。

保管棚の図は棚の配置と明暗だけを資料として示す。下部の操作例は採用しない。図の観察文も反転や押す色を直接教えない。実物を操作したときの沈み込みは維持する。
